# Rincón Sur Probadores

Aplicación móvil desarrollada en **Kotlin** con **Jetpack Compose** para la gestión de turnos y probadores en la tienda Retail

## Funcionalidades
- Solicitud y reserva de turnos para clientes.
- Aplicación de reglas de negocio para la asignación de turnos.
- Interfaz moderna migrada de XML Views a Jetpack.

## Cómo ejecutar el proyecto
1. Clona este repositorio en tu computadora:
   git clone [https://github.com/Slayer248/RinconSurProbadores.git](https://github.com/Slayer248/RinconSurProbadores.git)

2.Abre Android Studio y selecciona Open (Abrir).

3.Navega hasta la carpeta RinconSurProbadores que clonaste y selecciónala.

4.Espera a que Gradle sincronice y descargue todas las dependencias.

5.Conecta un dispositivo Android (con depuración USB activada) o inicia un Emulador en Android Studio.

6.Presiona el botón Run (el triángulo verde o Shift + F10) para compilar y ejecutar la aplicación.
